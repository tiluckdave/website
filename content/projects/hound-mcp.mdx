I code with AI agents everyday. While watching an agent scaffold a service, I realized it casually ran `npm install` on packages without checking anything. Agents have root execution access in your terminal with zero supply chain awareness.

If an agent installs a typosquatted library or a version with an active CVE, the exploit happens before you even review the PR.

I built Hound MCP as a local, zero-config Model Context Protocol server that gives agents tools to inspect packages before installing or committing them.

The hard rule was zero API keys. Most security tools fail on adoption because of onboarding friction. Hound runs locally over stdio and queries Google's public `deps.dev` and `OSV.dev` endpoints. Lockfiles are parsed with pure TypeScript regex across seven ecosystems, batching 100 packages per query so audits take seconds.

The trickiest part was typosquatting detection — balancing Levenshtein string distance against download velocity so new, legitimate packages don't trigger false alarms.

Today, Hound MCP is open source on npm with 12 tools to audit, pre-check, and score dependencies.

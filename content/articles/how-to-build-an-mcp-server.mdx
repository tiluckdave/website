Model Context Protocol (MCP) is an open standard that lets you build servers exposing tools, resources, and prompts to LLM applications. Once you build an MCP server, any MCP-compatible client (Claude Desktop, Cursor, Zed) can use it.

This guide walks through building a complete MCP server in TypeScript.

## What You'll Build

A simple MCP server that exposes:
- A `get_weather` tool that fetches weather data
- A `weather://current` resource for current conditions
- A prompt template for weather queries

## Prerequisites

- Node.js 18+
- TypeScript
- Basic understanding of how LLMs work

## Setting Up

```bash
mkdir my-mcp-server && cd my-mcp-server
npm init -y
npm install @modelcontextprotocol/sdk
npm install -D typescript @types/node
```

Initialize TypeScript:

```bash
npx tsc --init
```

## Writing the Server

Create `src/index.ts`:

```typescript
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { z } from "zod";

const server = new McpServer({
  name: "weather-server",
  version: "1.0.0",
});

// Register a tool
server.tool(
  "get_weather",
  "Get current weather for a city",
  { city: z.string().describe("City name") },
  async ({ city }) => {
    // In a real server, call an actual weather API
    return {
      content: [
        {
          type: "text",
          text: `Weather for ${city}: 22°C, partly cloudy`,
        },
      ],
    };
  }
);

// Start the server
const transport = new StdioServerTransport();
await server.connect(transport);
```

## Running It

```bash
npx tsc && node dist/index.js
```

## Connecting to Claude Desktop

Add to `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "weather": {
      "command": "node",
      "args": ["/path/to/my-mcp-server/dist/index.js"]
    }
  }
}
```

Restart Claude Desktop. You'll see the hammer icon indicating tools are available.

## What to Build Next

- Add more tools (forecasts, historical data, alerts)
- Add resource endpoints for static data
- Add prompt templates for common queries
- Publish to npm so others can use it
